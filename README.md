# 🚀 Network Tool + Speedtest (Auto Installer)

Tool sederhana berbasis **Windows CMD (.bat)** untuk:

* Melihat informasi jaringan (IP, DNS, Gateway, SSID, dll)
* Menjalankan **Speedtest CLI**
* Melakukan **ping test**
* Traceroute (menu 2)

---

## 📦 Fitur

* 📊 Dashboard jaringan (WiFi / LAN)
* 🌐 Public IP otomatis
* ⚡ Speedtest (Ookla CLI)
* 📡 Ping beberapa server
* 🛰️ Traceroute

---

## ⚙️ Instalasi (1 Klik)

1. Download file:

   ```
   install_speedtest.bat
   ```
2. Klik kanan → **Run as Administrator**
3. Tunggu sampai selesai

---

## 📁 Hasil Instalasi

File akan otomatis dibuat di:

```
C:\Tools\
   speedtest.exe
   networktool.bat
```

---

## ▶️ Cara Menjalankan

Buka CMD, lalu jalankan:

```
C:\Tools\networktool.bat
```

atau jika PATH sudah aktif:

```
networktool
```

---

## 🖥️ Tampilan Menu

```
[1] RUN DASHBOARD
[2] TRACEROUTE
[0] EXIT
```

---

## 🔧 Kebutuhan Sistem

* Windows 10 / 11
* Internet aktif (untuk speedtest & public IP)
* Tidak perlu install Git

---

## ⚠️ Catatan

* Speedtest menggunakan **Ookla CLI**

* Jika muncul error:

  ```
  Too many requests
  ```

  berarti limit sementara → tunggu beberapa menit

* Jika command tidak dikenali:

  ```
  Tutup CMD → buka ulang
  ```
